# 可复用章节标题

依据 2026-10-08 老师介绍 Image2 v1 的标题框外形反向重建，非原图裁切。保留双线、内凹转角和左右短线。

- `section-heading-frame.svg`：无字透明矢量框，456×80，可无损缩放。
- `section-heading-frame@2x.png`：无字透明 PNG，912×160，便于交给其他排版工具。
- `section-heading.css`：统一组件样式，思源宋体 Bold，字号52px。
- `章节标题_复用示例.html`：三个实际活字标题，均调用同一 SVG 和 CSS。
- `章节标题_三种换字预览.png`：静态换字样张，不是浏览器截图。

使用：引入 CSS，放置 `<div class="section-heading"><h2>老师介绍</h2></div>`。后续只替换 h2 文字为“课程亮点”“课程大纲”等。当前尺寸适用于四字标题，更长标题需按实际长度调整，不能靠压缩字体硬塞。

框体不含文字，页面标题是活字，不需要再请求图像生成。当前课程入口母版已使用该组件。
