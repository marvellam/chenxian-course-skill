## 制作分工

- `image2-visual/`：gpt-image-2 基于用户提供的倪瓒作品生成的无字山水画面，有请求记录。它只承担入口局部氛围，不承载文案。
- `课程入口_可编辑母版.html`：文字是独立的 HTML 活字；题图、人物和 Logo 是独立图片。修改文案、字号、间距或换图后可重新导出。
- `assets/`：当前母版使用的山水画面、人物抠图和 `section-heading-frame.png` 小标题框体；Logo 与原始 image2 笔触仍保留在目录中。原始画作及人物素材仍保留在 `course-design/assets/`。
- `课程入口_预览.png`：本地导图，用于快速检查文字和素材，不能作为可编辑源文件。
- `课程入口_网页核对.png`：浏览器打开可编辑母版后的实际截图；审阅排版以此图为准。
- `课程入口_手机比例预览.png`：按 390px 手机宽度等比例缩放的检查图，不作为最终上传文件。
