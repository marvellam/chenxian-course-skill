# 中国美术史课程大纲更新工具

本工具供同事在自己的电脑上独立完成**课程大纲**的更新、预览和导出（详情页第06张），不需要编辑任何代码或 HTML 文件。

> **范围说明：** 本工具只负责大纲内容的日常更新。完整详情页（全套8张）的重新导出由 `scripts/export_detail_v1.py` 单独完成，属于非日常操作，不在本工具的日常使用流程内。

---

## 首次安装（约10分钟，只做一次）

### 第一步：安装 Python

打开 https://www.python.org/downloads/，下载最新版本（3.11 或更高）。

安装时勾选 **"Add Python to PATH"**（这一步很重要），其余选项默认即可。

### 第二步：获取工具包

从 GitHub 下载或克隆本仓库到你的电脑，例如放到：

```
C:\Users\你的用户名\课程工具\
```

如果安装了 Git，可以在命令提示符里运行：

```bash
git clone https://github.com/[仓库地址] 课程工具
```

如果没有 Git，在 GitHub 页面点击绿色 **Code** 按钮 → **Download ZIP**，解压即可。

### 第三步：安装依赖库

双击工具包里的 **`install.bat`** 文件，等待安装完成（需要联网，约1-3分钟）。看到"安装完成"字样即可。

### 第四步：安装字体

打开工具包里的 `fonts\` 文件夹，全选所有字体文件，右键 → **为所有用户安装**。

> 字体已包含在工具包里，不需要另外下载。

### 第五步：打开 Agent

在你的 AI Agent 软件（Claude Code、Cursor 等）里，将工作目录设为本工具包的文件夹。`SKILL.md` 会自动被识别为操作指令。

## 日常使用

安装完成后，每次更新大纲只需要对 Agent 说：

> "读取飞书最新大纲，告诉我这次改了哪些内容。"

Agent 会：
1. 读取飞书多维表格里的最新大纲
2. 与当前确认内容对比，列出变动
3. 等你确认后生成预览（HTML + PNG）
4. 确认无误后导出交付图片
5. 询问 NAS 路径后复制过去

---

## 注意事项

- **不要直接修改 `output/outline-editable-v1/content.json`**，通过飞书更新内容，让 Agent 来更新这个文件
- **不要直接修改任何 HTML 文件**，排版由脚本自动完成
- 飞书里空白或未完成的课题不会覆盖已确认内容，不用担心误删
- 导出到 NAS 时，旧版本目录会保留，不会覆盖

## 遇到问题

- **字体报错**：确认第四步已安装字体，或检查 `fonts\` 目录是否完整
- **Python 报错**：确认安装时勾选了"Add to PATH"，重新安装一次
- **飞书读取失败**：检查飞书账号授权，或联系负责人
- **其他错误**：把完整错误信息截图发给负责人

## 文件说明

| `SKILL.md` | Agent 操作手册（不需要阅读，供 Agent 读取） |

| `output/detail-entry-v1/` | 完整详情页母版 |
| `package-version.txt` | 当前工具包版本号 |
