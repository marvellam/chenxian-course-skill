## 文字可编辑性

`content.json`是本模块文字源。24个题目均在HTML中以文本节点呈现，未生成字形图片或转为路径。每讲有独立data-lesson标记；作品装饰与文本分层。后续修改JSON中的标题后，运行`../../build_outline_editable.py`，会重新测量换行、段高、页高并更新整页及单独两平台母版。修改不需要重新生成画作或使用image2。

目录正文44px思源黑、行高64px，讲次40px；篇章标题68px思源宋Heavy；大纲提示40px。须知正文44px；客服提示38px思源黑Bold（700）。常见问题已按本轮反馈移除。

三篇章标题背景分别使用用户提供的范宽《溪山行旅图》山石、吴炳花鸟、梁楷人物右侧画幅。使用原画山石、荷花和右侧人物轮廓，以SVG裁切路径加细描边和轻投影呈现，保留原画色彩与笔触，无AI补画。标题区域仍为900×260，移除第一篇、第二篇、第三篇标记，目录位置不变。装饰只出现在篇章头部，不铺在目录文字下。
